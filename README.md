## 🚀 Featured Projects

### 🌊 [OrderWave](https://github.com/Nagalakshmi-N-03/OrderWave) — E-commerce Data & Demand Forecasting Platform
> *Production-grade data pipeline simulating the backend data platform of companies like Flipkart and Nykaa*

[![Live Dashboard](https://img.shields.io/badge/Live%20Dashboard-Streamlit-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://nagalakshmi-n-03-orderwave-dashboardapp-4y9yyo.streamlit.app)

Raw e-commerce data flows through a fully automated pipeline — ingested into PostgreSQL, transformed with dbt, forecasted with Prophet, and served on a live Streamlit dashboard backed by Supabase.

| Layer | Tool |
|---|---|
| Containerization | Docker |
| Database | PostgreSQL + Supabase |
| Orchestration | Apache Airflow 2.8 |
| Transformation | dbt 1.7 (star schema, 8 data quality tests) |
| Forecasting | Prophet (Meta) — 30-day demand forecast |
| Dashboard | Streamlit + Plotly |

```
Raw CSV → PostgreSQL → Airflow DAG → dbt (staging + marts) → Prophet → Streamlit Cloud
```

**What I built:** Docker setup, raw schema, 3 ingestion scripts, Airflow DAG, dbt staging views + mart tables + quality tests, Prophet demand forecasting, low-stock email alerts, and a live deployed dashboard.
